# مراجعة القرآن (أندرويد، بدون إنترنت)

## طريقة الحصول على التطبيق (بدون تثبيت أي شيء على جهازك)
1. أنشئ حساباً مجانياً على github.com، ثم اضغط **New repository** وسمّه مثلاً `quran-review`، واجعله **Public**.
2. افتح المستودع واختر **uploading an existing file**، ثم اسحب إليه **كل محتويات** هذا المجلد (بعد فك الضغط)، بما فيها مجلد `.github`، ثم **Commit changes**.
   - إن لم يظهر مجلد `.github` بعد الرفع: اختر **Add file ← Create new file**، واكتب الاسم `.github/workflows/build.yml`، والصق فيه محتوى ملف `build.yml` ثم احفظ.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**. يستغرق البناء نحو 10 إلى 25 دقيقة.
4. عند اكتماله افتح **Releases** (في العمود الأيمن من صفحة المستودع) وحمّل **QuranReview.apk** على هاتفك وثبّته (اسمح بالتثبيت من مصدر غير معروف).
5. عند أول تشغيل: اسمح بالميكروفون، وانتظر تجهيز النموذج الصوتي (مرة واحدة فقط، ويحتاج نحو 1.5 جيجابايت مساحة فارغة). بعدها يعمل بالكامل بدون إنترنت.

إن فشل البناء: افتح الخطوة الحمراء في Actions وانسخ آخر 30 سطراً من الرسالة وأرسلها لي لأصلحها.

## ملاحظات
- التطبيق بلا إذن إنترنت أصلاً.
- نص القرآن: رواية حفص بالرسم العثماني، مضمَّن في التطبيق.
- النموذج الصوتي: Vosk عربي (vosk-model-ar-mgb2-0.4) برخصة Apache 2.0.
